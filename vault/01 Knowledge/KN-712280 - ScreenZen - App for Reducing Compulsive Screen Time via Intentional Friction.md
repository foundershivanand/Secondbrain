# ScreenZen - App for Reducing Compulsive Screen Time via Intentional Friction

## Core Idea

ScreenZen reduces compulsive app usage and doomscrolling by introducing intentional friction—such as timed pauses, reflection prompts, and cognitive exercises—before allowing access to flagged apps.

## Key Information

- ScreenZen inserts a customizable pause screen before opening flagged apps.
- It tracks the efficacy of interventions by counting how many times the friction successfully prevented the user from opening the app.
- Interventions include timed pauses (e.g., 5 seconds), conscious reflection prompts ('Is this important?'), and cognitive exercises (e.g., solving math equations).

## Insights

- Habit loops are highly vulnerable to micro-interventions that force conscious, deliberate thinking (System 2) over automatic behavior (System 1).
- Tracking 'saves' (the number of times friction successfully stopped an app open) gamifies self-control and provides positive reinforcement for habit change.

## Actions
