# 8 Essential Markdown Documentation Files Before AI Vibe Coding

## Core Idea

Before writing or generating a single line of code with AI ('vibe coding'), establish a standardized documentation foundation of 8 markdown files to enforce context, architecture, and boundaries on the model.

## Key Information

- The 8 foundational markdown files required under `/docs`: PRD.md, DESIGN_SYSTEM.md, ARCHITECTURE.md, DATABASE.md, SECURITY.md, CODE_STYLE.md, TESTING.md, and AGENTS.md.
- PRD.md breakdown includes 6 structured sections: 01 Product Overview, 02 Problem & Goal, 03 Target Users, 04 Core Features, 05 MVP Scope (Must Have vs. Later), and 06 Acceptance Criteria.
- Eliminates hallucination and drift during AI code generation by providing deterministic context before opening code prompts.

## Insights

- Treating LLM code generators as junior developers who require an exhaustive project handbook ensures modular, cohesive, and syntactically aligned code generation.
- Including an `AGENTS.md` file defines operating rules, tool usage constraints, and operational bounds specifically tailored for autonomous coding agents.
