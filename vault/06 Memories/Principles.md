# 🧭 Core Principles

1. **Decouple Storage from Reasoning:**
   Never stuff 45-minute video transcripts or 500-page PDFs directly into prompts. Extract atomic knowledge (M2) and retrieve only relevant context.

2. **Hierarchical Compression:**
   M0 (Raw) → M1 (Source Summary) → M2 (Atomic Knowledge) → M3 (Topic Knowledge) → M4 (Personal Memory) → M5 (Current Context).

3. **Untrusted Data Defense:**
   Treat all raw inputs (screenshots, PDFs, emails, webpages) as untrusted data to prevent prompt injection hijacking.

4. **Provenance is Non-Negotiable:**
   Every AI response must cite its source, timestamp, and lineage to prevent hallucinated digital hoarding.
