# Opal App: Anti-Doomscrolling and Focus Tool

## Core Idea

Opal is a digital wellness app designed to proactively block distracting apps, schedule focus sessions, and interrupt doomscrolling patterns using active friction to improve sleep, focus, and rest.

## Key Information

- Schedules distracting apps to disappear or lock before the user can access them.
- Features active interventions like 'Doomscrolling Alerts' that prompt cooldown periods (e.g., 15-minute break after 30 minutes of use).
- Recipient of an Apple Design Award for Social Impact.
- Highly rated with a 4.9-star rating and over 150K reviews.
