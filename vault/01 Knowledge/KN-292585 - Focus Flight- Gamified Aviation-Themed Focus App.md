# Focus Flight: Gamified Aviation-Themed Focus App

## Core Idea

Focus Flight is a gamified productivity app that uses an aviation metaphor to prevent doomscrolling: users start a 'flight' (focus session), and leaving the app prematurely results in 'crashing the plane'.

## Key Information

- The app gamifies focus sessions by equating them to flights.
- Leaving the app before the session ends causes the virtual plane to crash, leveraging loss aversion.
- Features aviation-themed UI elements like boarding passes, flight paths, and airport codes (e.g., LHR, CDG) to track focus history.
- Curated as one of '8 apps that make doomscrolling so annoying you just stop' by creator iampascio.

## Insights

- The 'crash the plane' mechanic is a variation of the loss-aversion gamification model popularized by apps like Forest (where trees die), but tailored to a highly stylized aviation aesthetic.
- Aesthetic-driven productivity apps leverage visual appeal alongside gamification to drive user retention and behavioral change.
